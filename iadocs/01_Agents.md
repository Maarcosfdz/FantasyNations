# AGENTS.md

## Project

This repository contains a private fantasy, prediction and challenge application for an international football tournament.

The app is designed for private leagues between friends. Users can create leagues, join by invitation, build fantasy squads, make match predictions, complete challenges and view rankings.

The project must be simple, secure, maintainable and cheap to run.
